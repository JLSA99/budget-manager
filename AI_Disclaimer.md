# AI Usage Disclosure

## Summary

I used an AI assistant (Claude, by Anthropic) while building this Personal Budget Manager project. I used it as a **tutor and learning aid**, not as a tool to copy and paste finished work.

## How I used AI

- **Explanations:** The AI explained what each function and file does (`cli.py`, `services.py`, `storage.py`, `validation.py`, and the tests), so I could understand how the program is structured and why.
- **Guidance while writing code:** The AI helped me write and improve some lines of code. I went through its suggestions to understand them, and I made decisions about how to use them in my project.
- **Concepts:** The AI helped me understand ideas used in the project, such as input validation, separating code into layers, and testing with pytest.

## What I did myself

- I reviewed, ran, and tested the code to check that it works.
- I made sure I understand the code well enough to explain it and modify it.
- The project is not an unedited copy of AI output.

## Tools

- AI assistant: Claude (Anthropic)
- Editor: Visual Studio Code
